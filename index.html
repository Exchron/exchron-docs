Exchron Documentation

Welcome to Exchron, a web application designed to make exoplanet data classification accessible to everyone. Exchron empowers users to explore, analyze, and classify exoplanet data using advanced AI and machine learning algorithms—all through an intuitive, beginner-friendly interface.

What is Exchron?​

Exchron bridges the gap between complex machine learning tools and real-world exoplanet research. Whether you're an expert researcher or a curious enthusiast, Exchron provides a platform to upload new datasets, experiment with multiple classification models, and customize workflows to suit your needs. The platform is designed for both advanced users seeking powerful analytics and beginners looking for hands-on learning opportunities.

How It Works​

When you visit Exchron, you can immediately try out the application or explore the documentation—no sign-up required. The platform features two main dashboards:

  • Playground Mode:

    • Experiment with pre-built models and view performance metrics.
    • Upload new exoplanet data for classification.
    • Analyze results and optimize models using built-in tools.

  • Classroom Mode:

    • Step-by-step guidance for preparing datasets, selecting models, training, validating, and exporting results.
    • Designed for beginners to learn about machine learning and exoplanet science interactively.

An integrated AI assistant is available to answer questions, guide users through the interface, and help with data classification or model creation.

Benefits & Impact​

Exchron is more than just another AI/ML tool. It makes machine learning approachable and engaging, allowing users to:

  • Interact with real exoplanet data and experiment with different models.
  • Gain hands-on experience in data science and machine learning.
  • Contribute to a collaborative, open-source community.
  • Inspire curiosity and learning in STEM fields for students, hobbyists, and researchers alike.
