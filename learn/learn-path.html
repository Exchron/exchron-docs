Learning Path: Learn → Dashboard

Use this short path to move from concepts to hands‑on practice.

  1. Start on Exchron Learn

    • Read the Overview of Exoplanets and related topics
    • Try the Exoplanet Simulator to build intuition

  2. Move to Dashboard — Playground

    • Experiment with inputs on a model and see predictions change
    • Use the results sections to understand confidence and metrics

  3. Move to Dashboard — Classroom

    • Follow the guided flow: data → model → train → test → export
    • Try different models (e.g., Neural Network, Random Forest)

  4. Reflect and iterate

    • Revisit Learn pages to reinforce concepts as questions arise
    • Try new datasets or tweak model settings in the Dashboard
